# Smiles by Noetzel Website

Immersive dental-practice website for Smiles by Noetzel / Ashland Dental & Wellness Center.

## Stack

- Astro
- GSAP
- Tailwind CSS

## Local development

```sh
npm install
npm run dev
```

The development server runs at `http://localhost:4321` by default.

## Production build

```sh
npm run build
npm run preview
```

The static production output is generated in `dist/`.
